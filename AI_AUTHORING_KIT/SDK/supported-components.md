# Supported components

| Component | How to author |
|---|---|
| Room (interior) | `walls` + `floor` + `ceiling` |
| Landscape (exterior) | `floor` + `sky`, omit walls/ceiling |
| Primitive object | `kind` + `material` + `position` |
| Catalog geometry | `kind: concept` + `concept` |
| Cutout | `window` |
| Player | `spawn` / `player` |
| Zone | `zones[]` |
| NPC | `npc[]` |
| Mission | `missions[]` |
| Quiz | `quizzes[]` |
| Event | `events[]` |
