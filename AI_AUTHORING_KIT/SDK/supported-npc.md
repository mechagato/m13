# Supported NPC

Roles: teacher, guide, peer, narrator, evaluator.

`dialog` is an array of strings (shown in order) or objects `{text, when: idle|mission|success|hint, mission}`.

`voice` is an optional id for TTS runtimes. This kit does not ship audio files.

Place NPC on the floor. The Education Demo draws a capsule ~1.7 m tall.
