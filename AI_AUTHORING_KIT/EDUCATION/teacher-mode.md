# Teacher mode

`education.mode: teacher` (optional). Runtime shows:

- Students (local session in the Demo)
- Progress (missions done / XP)
- Heatmap (visited zones)
- Replay timeline
- Teleport (enter the world)
- Reset
- Export CSV / (PDF later)

Authoring: you do not list students in the `.m13`. The file is the lesson; the runtime binds learners.
